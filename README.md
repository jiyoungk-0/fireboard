# 🔥 파이어보드 (FireBoard)

경제적 자유(FIRE)를 목표로 하는 개인 자산·배당 트래커입니다. 현금, 적금·예금, 주택청약, 국내/해외 주식을 한곳에서 관리하고, 매달 들어오는 배당·이자를 추적하면서 목표 자산까지 얼마나 남았는지 실시간으로 보여줍니다.

**Live Demo**: https://fireboard-921a5.web.app

## 스크린샷

> 대시보드 · 보유자산 · 주식 포트폴리오 3개 탭으로 구성된 모바일 우선 웹앱입니다.

## 주요 기능

- **Google 로그인 + 실시간 동기화** — Firebase Authentication과 Firestore로 폰/PC 어디서든 같은 데이터를 실시간으로 확인
- **다양한 계좌 유형 지원** — 입출금(현금), 적금, 예금, 주택청약종합저축을 각각 다른 계산 로직으로 처리
  - 적금·예금: 거치식/적립식(매월·매주·매일) 납입 방식에 따라 회차별 단리 이자 자동 계산
  - 주택청약: 국토교통부 고시 예치기간별 차등금리(1개월 미만 0% · 1년 미만 2.3% · 2년 미만 2.8% · 2년 이상 3.1%)를 자동 반영
- **국내·해외 주식 포트폴리오** — 종목별 평단가/현재가/배당률/배당 주기(매월·분기·반기·연 1회)를 입력하면 이번 달 실제 지급 여부까지 계산
  - 미국 배당은 한미 조세조약상 원천징수 15%를 반영, 국내 배당·이자는 세전 기준
  - 실시간 환율(open.er-api.com) 연동으로 달러 자산을 원화로 자동 환산, 원/달러 보기 전환 가능
- **파이어 목표 역산** — 원하는 월 배당·이자 목표와 예상 연 배당률을 입력하면 필요한 목표 자산을 자동으로 계산
- **자산 이력 추적** — 매일 스냅샷을 저장해 전달·전년 대비 총자산·배당 증감을 비교
- **드래그로 순서 변경** — 계좌·종목 목록을 손으로 끌어서 원하는 순서로 정렬(SortableJS), 수익률·투자금액·가나다순 정렬도 지원
- **PWA** — 홈 화면에 추가하면 네이티브 앱처럼 아이콘과 함께 실행

## 기술 스택

- **Frontend**: Vanilla JavaScript(ES Modules), 빌드 도구 없이 순수 HTML/CSS/JS
- **Backend**: Firebase Authentication(Google 로그인), Cloud Firestore(실시간 DB), Firebase Hosting
- **외부 API**: [open.er-api.com](https://www.exchangerate-api.com/) (무료 실시간 환율)
- **라이브러리**: [SortableJS](https://sortablejs.github.io/Sortable/) (드래그 앤 드롭)

## 프로젝트 구조

```
public/
  index.html        # 전체 UI 마크업 + 스타일
  app.js            # 인증, Firestore 연동, 이자·배당 계산 로직, 렌더링
  manifest.json      # PWA 매니페스트
  icons/            # 앱 아이콘
firestore.rules      # Firestore 보안 규칙 (사용자별 데이터 격리)
firebase.json         # Firebase Hosting 설정
```

## 보안

Firestore 보안 규칙으로 `request.auth.uid`가 일치하는 사용자만 자신의 데이터를 읽고 쓸 수 있도록 격리되어 있습니다. 클라이언트에 노출된 Firebase 설정값(`apiKey` 등)은 Firebase 특성상 비밀값이 아니며, 실제 접근 제어는 이 보안 규칙이 담당합니다.

## 만든 이유

가계부 앱은 많지만 "이자·배당만으로 얼마나 벌고 있고, 목표까지 얼마나 남았는지"를 한눈에 보여주는 도구는 마땅치 않아서 직접 만들었습니다.
